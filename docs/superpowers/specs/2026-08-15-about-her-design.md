# “关于她”产品设计

## 产品目标

“关于她”是一个单人物、手机优先的私密记忆应用。用户可以像发消息一样保存文字、图片和语音，系统保留原始素材，并把可验证的信息整理为喜欢、不喜欢、原话、重要的人与事、习惯与边界、愿望六类档案。

应用不替她说话，也不把推测包装成事实。每条档案结论必须能回到原始记录；明确表达可以自动展示，推测只能进入待确认区。

## 核心体验

- 首页优先展示人物档案和最近确认的信息，右下角提供快速记录入口。
- 底部导航固定为“档案、记录、回忆、问记录”，设置从页面右上角进入。
- 文字、最多四张图片和一段五分钟以内的语音可以组成一条记录。
- 图片和语音原件保存在私有存储中；转写、识别结果允许修正并重新分析。
- 前后冲突的信息保留时间版本，旧结论标记为已更新，不被静默覆盖。
- 问记录只引用现有证据；证据不足时直接说明不知道。

## 视觉系统

采用已批准的“安静温柔”方向：暖白背景、炭黑文字、克制玫瑰色操作、墨绿摘要区。界面以开放列表和少量功能面板为主，不复制 Kitty 卡通风格，不使用大面积渐变、装饰光斑或嵌套卡片。

## 隐私与边界

- 使用独立 Supabase 项目、独立认证、独立私有存储和行级权限。
- OpenAI 密钥只存在于 Edge Function 环境变量中。
- 不从照片表情推断性格、态度或关系信号。
- 首版不支持多人物、历史聊天批量导入、主动关系提醒或模拟她的口吻。
- 支持完整 JSON、可读 Markdown 导出，以及二次确认后的永久删除。
