# “关于她”实施计划

> **执行要求：** 按测试先行顺序完成，每个阶段必须通过对应测试和生产构建后再进入下一阶段。

**目标：** 交付一个本地可运行、可配置独立 Supabase/OpenAI、可部署到 GitHub Pages 的移动端 PWA。

**技术栈：** React、TypeScript、Vite、Vitest、Testing Library、Supabase、OpenAI Responses/音频接口、GitHub Actions。

## 全局约束

- 单人物，中文界面，手机优先。
- 原始记录不可被 AI 改写；所有结论可追溯来源。
- 明确事实和推测使用独立状态，不展示伪置信度百分比。
- 未配置云端时保留本地可用模式，不伪造 AI 分析结果。
- OpenAI 模型必须由服务端环境变量提供，不硬编码未经官方文档核验的型号。

## 任务

- [x] 建立项目、设计系统、数据类型和领域测试。
- [x] 实现本地档案、记录、待确认、回忆、搜索和问记录体验。
- [x] 实现 IndexedDB 草稿、媒体约束、导出和删除流程。
- [x] 实现 Supabase 数据模型、RLS、私有存储与客户端适配器。
- [x] 实现 `analyze-entry`、`ask-memory`、`delete-account` Edge Functions。
- [x] 完成 PWA、GitHub Pages 工作流、自动化测试和真实浏览器验收。

> GitHub Pages 与独立 Supabase 已部署：线上使用免费邮件登录链接、云端同步、RLS 和私有媒体存储。OpenAI 服务端密钥尚未配置，AI 分析功能仍待启用。
