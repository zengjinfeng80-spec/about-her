# 邮箱验证码登录实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将“关于她”的邮箱链接登录改为同页两步式 6 位邮箱验证码登录。

**Architecture:** 保留 `CloudApp` 现有 Supabase 客户端、会话监听和档案加载逻辑，仅将未登录页拆成“输入邮箱”和“输入验证码”两个状态。发送仍使用 `signInWithOtp`，提交验证码使用 `verifyOtp`；Supabase 邮件模板只渲染 `{{ .Token }}`。

**Tech Stack:** React 19、TypeScript、Supabase JS 2、Vitest、Testing Library、Supabase CLI、GitHub Pages。

## 全局约束

- 验证码为 6 位数字，有效期固定为 600 秒。
- 发送频率限制保持 60 秒，不在前端另造倒计时器。
- 保留现有注册、会话持久化、数据权限和登出行为。
- 保留旧邮件链接的 `otp_expired` 中文提示，用于过渡期错误处理。
- 不新增密码、第三方、手机号或找回密码流程。

### 任务 2：实现同页两步式登录

**Files:**
- Modify: `src/cloud/CloudApp.tsx`
- Modify: `src/styles.css`
- Test: `src/cloud/CloudApp.test.tsx`

**Interfaces:**
- Consumes: `(email: string) => Promise<void>` 发送回调、`(email: string, token: string) => Promise<void>` 验证回调。
- Produces: `LoginPage({ onSend, onVerify, initialMessage })` 的两步登录 UI。

- [ ] **Step 1: 将发送调用改为纯 OTP 请求**

```ts
const { error: signInError } = await client.auth.signInWithOtp({
  email,
  options: { shouldCreateUser: true },
});
```

- [ ] **Step 2: 注入验证回调**

```ts
onVerify={async (email, token) => {
  const { error: verifyError } = await client.auth.verifyOtp({
    email,
    token,
    type: 'email',
  });
  if (verifyError) throw verifyError;
}}
```

- [ ] **Step 3: 实现 `email` 和 `code` 两个页面状态**

```ts
const [step, setStep] = useState<'email' | 'code'>('email');
const [email, setEmail] = useState('');
const [token, setToken] = useState('');
```

发送成功后执行 `setStep('code')`；“修改邮箱”执行 `setStep('email')`、`setToken('')` 和 `setMessage('')`。

- [ ] **Step 4: 渲染 6 位数字验证码表单**

```tsx
<input
  required
  aria-label="6 位验证码"
  inputMode="numeric"
  autoComplete="one-time-code"
  pattern="[0-9]{6}"
  maxLength={6}
  value={token}
  onChange={(event) => setToken(event.target.value.replace(/\D/g, '').slice(0, 6))}
/>
```

验证码页同时显示“验证并登录”、“重新发送”和“修改邮箱”按钮。重新发送复用 `onSend(email)` 并显示成功或错误信息。
