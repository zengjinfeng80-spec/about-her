# 雪梨加载性能优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 减少云端模式打开档案和保存记录时的重复请求，同时保持现有数据和交互规则不变。

**Architecture:** `SupabaseMemoryService.loadSnapshot` 继续负责首次完整快照，但媒体签名 URL 改为可选的延迟步骤；`createEntry` 在写入完成后直接返回新记录，避免再次拉取全部快照；媒体上传改为并行。`CloudApp` 增加认证初始化失败提示。

**Tech Stack:** React 19, TypeScript, Supabase JS, Vitest, Vite PWA.

## Global Constraints

- 不改变现有档案分类、自动入档、手动入档和离线草稿规则。
- 不新增模型调用，不修改数据库结构或 RLS。
- 正式账号继续使用 Supabase，本地/demo 模式继续使用当前本地状态。
- 保留自动入档失败时原始记录不删除的行为。
