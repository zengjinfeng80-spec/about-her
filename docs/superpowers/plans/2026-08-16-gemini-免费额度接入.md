# Gemini 免费额度接入实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将“雪梨”的文字、图片、录音分析和“问记录”切换到 Gemini API 免费额度，并在线上完成真实验证。

**Architecture:** 用一个专用 Gemini 适配器取代 OpenAI 适配器，Edge Function 继续负责鉴权、读取私有媒体和写入现有事务。媒体由服务端临时上传到 Gemini Files API，请求结束后清理；结果仍通过本地契约校验后才落库。

**Tech Stack:** Supabase Edge Functions、Deno TypeScript、Gemini REST API、React 19、Supabase JS 2、Vitest、GitHub Pages。

## 全局约束

- Gemini 密钥只能保存在 Supabase Edge Function Secrets。
- 不增加 OpenAI 自动备用、多供应商路由或前端模型选择器。
- 保持现有六个分类、事实/推测区分、证据引用和照片推断禁止规则。
- 保持最多 4 张图片、一段 5 分钟录音和单文件 25 MB 限制。
- 免费额度耗尽时不切换付费服务，只保留失败任务并允许用户重试。
- 模型名不写死，用取得密钥后的官方列表和最小真实请求确认。

- [ ] **Step 6: 实现最小 Gemini 适配器**

```ts
export type GeminiInput =
  | { type: 'text'; text: string }
  | { type: 'media'; blob: Blob; filename: string };

export async function structuredResponse(options: {
  modelEnv: string;
  instructions: string;
  content: GeminiInput[];
  schema: Record<string, unknown>;
}) {
  const uploaded: GeminiFile[] = [];
  try {
    const parts = await inputsToParts(options.content, uploaded);
    const response = await geminiFetch(`/v1beta/models/${requiredModel(options.modelEnv)}:generateContent`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        systemInstruction: { parts: [{ text: options.instructions }] },
        contents: [{ role: 'user', parts }],
        generationConfig: { responseMimeType: 'application/json', responseJsonSchema: options.schema },
      }),
    });
    return JSON.parse(extractGeminiText(await response.json())) as unknown;
  } finally {
    await Promise.allSettled(uploaded.map((file) => deleteFile(file.name)));
  }
}
```

`inputsToParts` 先累计媒体字节：总量不超过 `15 * 1024 * 1024` 时使用 `inlineData`，超过时将本次请求的媒体都交给 `uploadFile`，避免 base64 膨胀后超过上游请求限制。`uploadFile` 使用 Gemini Files API 的可恢复上传流程，上传后轮询文件直到 `ACTIVE`；`FAILED` 或 30 秒未就绪时抛出明确错误。`geminiFetch` 对 429 返回固定中文限额提示，对其他非 2xx 返回状态码和经截断的上游错误。

- [ ] **Step 3: 实现结构化错误解析**

```ts
export async function functionErrorMessage(error: unknown) {
  if (error && typeof error === 'object') {
    const context = (error as { context?: unknown }).context;
    if (context && typeof context === 'object' && typeof (context as { json?: unknown }).json === 'function') {
      try {
        const payload = await (context as { json(): Promise<unknown> }).json();
        if (payload && typeof payload === 'object' && typeof (payload as { error?: unknown }).error === 'string') {
          return (payload as { error: string }).error;
        }
      } catch { /* 使用 message 兜底 */ }
    }
    if (typeof (error as { message?: unknown }).message === 'string') return (error as { message: string }).message;
  }
  return '服务器处理失败';
}
```
