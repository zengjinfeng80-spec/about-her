# “关于她”视觉对照与验收记录

## 对照基准

- 已批准方向：A“安静温柔”。
- 结构基准：首页档案优先，底部为“档案、记录、回忆、问记录”。
- 实现截图保存在本机视觉产物目录：
  - `about-her-desktop.png`
  - `about-her-mobile.png`
  - `about-her-record-mobile-fixed.png`
- 批准概念仍在用户打开的 `data:` 浏览器页中。浏览器安全策略禁止自动接管该页面并归档截图，因此没有绕过策略生成概念截图。

## Fidelity ledger

| 对照项 | 批准方向 | 当前实现 | 结论 |
| --- | --- | --- | --- |
| 色彩 | 暖白、炭黑、墨绿、克制玫瑰 | 四个主色保持一致，另用低饱和黄表示待确认 | 一致 |
| 首页层级 | 人物档案和细节数量先出现 | 首屏先显示标题、摘要、待确认和分类档案 | 一致 |
| 信息密度 | 像认真整理的私人手册 | 开放列表为主，卡片只用于摘要、输入和确认 | 一致 |
| 导航 | 档案、记录、回忆、问记录 | 四项名称、顺序和固定位置一致 | 一致 |
| 快速记录 | 玫瑰色圆形加号 | 非记录/设置页保留；记录页隐藏以免遮挡内容 | 有意优化 |
| 状态表达 | AI 提取与推测可区分 | 明确信息标“AI 从记录中提取”，推测仅进入待确认 | 一致 |

## 浏览器验收

- 桌面视口：`1280×720`，标题正确，页面非空，无框架错误覆盖层，控制台无警告或错误。
- 手机视口：`390×844`，`scrollWidth` 等于 `390`，无横向溢出。
- 点通：待确认、确认入档、证据抽屉、文字与图片记录、单条删除确认、时间线、搜索、问记录引用、设置和永久删除确认。
- 录音按钮在真实浏览器中触发了权限请求，但自动化环境不能完成麦克风授权后的采音；文件约束和时长边界由单元测试覆盖。
- JSON/Markdown 内容生成由单元测试覆盖。浏览器未捕获到程序化 Blob 下载事件，因此不把下载动作列为已通过的浏览器证据。
